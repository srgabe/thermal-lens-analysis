# Thermal Lens Spectroscopy Data Analysis 🔬📊

Este repositório contém ferramentas em Python desenvolvidas para automatizar o processamento e a análise de dados obtidos via **Espectroscopia de Lente Térmica (LT)**. 

O projeto foca-se na extração de parâmetros termo-ópticos a partir de sinais experimentais, substituindo fluxos de trabalho manuais por um pipeline de dados eficiente.

## 🚀 Funcionalidades
- **Data Cleaning:** Processamento de ficheiros brutos (.txt) com tratamento de ruído.
- **Curve Fitting:** Implementação de modelos teóricos para ajuste de curvas utilizando `scipy.optimize`.
- **Visualização Científica:** Geração de gráficos de alta resolução para análise de fase e amplitude do sinal.
- **Cálculo de Parâmetros:** Determinação de difusividade térmica e eficiência quântica de nanomateriais.

## 🛠️ Stack Tecnológico
- **Python 3**
- **Pandas & NumPy:** Manipulação de matrizes e séries temporais.
- **Matplotlib:** Visualização de dados científicos.
- **SciPy:** Optimização e ajuste de modelos não lineares.

## 📈 Resultados
Os scripts permitem uma redução drástica no tempo de análise, garantindo precisão estatística na caracterização de nanofluidos e materiais bidimensionais (como Óxido de Grafeno).
